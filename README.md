# 16Personalities Test

36 道截图来源题，E/I 12 道、N/S 12 道、T/F 12 道。七级回答，三组独立计分，结果显示一位小数。

免费自我探索网页，无账号、无收费、无答题数据上传。不是官方 MBTI 或 16Personalities 测评，未经过信效度验证。

原有 E/I 10 道全部保留，补入电话、人脉交流两题。N/S 纳入新观点、道德两难讨论、新方法、作品解读、新体验、虚构写作、理论、创意表达、复杂新颖想法、未来理论、抽象哲学和创意解决方案共 12 道。英文与截图位置见 questions.js。依据此前已读取的十张截图，不是新编题。

每题 weights.ei / weights.ns / weights.tf 的 +1 表示赞成支持 E / N / T，-1 支持 I / S / F，0 不参与该维度。每组百分比 = Σ(3×|权重| + 回答×权重) / Σ(6×|权重|) ×100；回答为 -3 至 +3。引擎支持同题双维度独立计分，但本题库没有经过验证的跨维度权重，因此每题只归入主要维度，不因同一句出现社交/讨论而重复算分。

电话、人脉压力、道德讨论、创作职业等题可能受习惯、紧张、兴趣与经验影响；按用户要求完整纳入相关题，不代表单题具有独立诊断效力。其余未纳入的 24 题涉及规划、截止日期、情绪调节、压力与自信等，不混入这三个维度。

N/S 概念参考：https://www.themyersbriggs.com/en-us/support/mbti-facts

部署继续使用本仓库 main 根目录的 GitHub Pages，不涉及其他网站。

## T/F 扩展

保留全部已有题目和 E/I、N/S 计分。新增 12 道涉及事实与情感说服、诚实与体谅、效率与感受、逻辑推理与个人价值的题目，按主要维度计分。英文原文与截图位置见 questions.js。截图 8 第 5 题“情绪控制你多于你控制情绪”属于情绪调节，不能据此将人判为 F；其他压力、情绪波动、自信类题不计入 T/F。截图 2 第 1 题“道德两难讨论”保留在 N/S；喜欢讨论道德并不能独立判定选择逻辑还是价值，故不重复计分。

三组均有倾向时给出 ENT、ENF、EST、ESF、INT、INF、IST、ISF 之一，并列出仅末位 J/P 不同的两种 MBTI 类型；任一组 50/50 时使用 X，保留该维度双方的类型。不把三字母结果当完整四字母定型。T/F 测决策偏好，不是智力、同理心能力或情绪稳定性的高低。该自定义题库与计分仍未经信效度校准。
