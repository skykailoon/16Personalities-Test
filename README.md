# 16Personalities Test

60 道题，按原先 10 张截图顺序排列；每页 6 题，共 10 页。原图当前不在原文件路径，本次依据聊天中已读取的完整截图内容与已存题库整理。每题的英文原文、中文翻译、出处、主维度、权重与归类理由见 questions.js。

## 计分与限制

四个字母维度 E/I、N/S、T/F、J/P 各有 12 道主要题；另 12 道主要题作为“压力与自信自评”，不用于四字母标签，不是心理健康筛查或诊断。全部 60 题都进入结果计算，没有用中立默认值补漏答。

七级答案依次为 +3,+2,+1,0,-1,-2,-3。每个维度独立计算：正向分 = Σ(3×|w| + w×答案)，满分 = Σ(6×|w|)，正向百分比 = 正向分/满分×100。负向 = 100−正向。0 权重不贡献分数，也不进入该组分母。正向为 E/N/T/J/较平稳，负向为 I/S/F/P/较敏感。先完整汇总，再统一保留一位小数。

## 多维度题审阅

所有题逐题审阅。主维度权重为 1；只给可指出具体语义依据的次维度 0.5 权重。该规则是人工设计的暂定计分方案，不是原网站官方算法，也不是经统计验证的因子载荷。多计维度不等于更准确。

- 第 41 题（截图 7 第 5 题）：陌生人交流压力同时计 I（1）和压力敏感（0.5）。
- 第 57 题（截图 10 第 3 题）：创意方案相对于具体步骤主要计 N（1），开放而非预设流程暂计 P（0.5）。此跨维度解释不确定，需真实样本验证。
- 其余 58 题只计主要维度：事实对感受测 T/F，不能因“事实”就另算 S；情感直觉不等同于 N；喜欢讨论不等同于 E；整洁不等同于 S；情绪波动不等同于 F。

人格百分比是本自定义题组的归一化答题倾向，不是准确率、概率或人群排名。中文翻译、选题与权重未经信效度校准。原网页的讨论兴趣、职业偏好、电话习惯、情绪化措辞均可能混入其他因素，不应把单题当独立诊断。

## 使用

无需账号、无收费、无答题数据上传，刷新会清空。每页需全部作答才能进入下一页；可返回修改。最后一页答完才计算结果。50/50 用 X 保留双方类型，压力自评不改变四字母结果。网页为自我探索工具，不是官方 MBTI 或 16Personalities 测评。

GitHub Pages 继续从本仓库 main 根目录发布，不改动其他网站。
