# 16Personalities Test

24 道截图来源题，E/I 12 道、N/S 12 道。七级回答，两组独立计分，结果显示一位小数。

免费自我探索网页，无账号、无收费、无答题数据上传。不是官方 MBTI 或 16Personalities 测评，未经过信效度验证。

原有 E/I 10 道全部保留，补入电话、人脉交流两题。N/S 纳入新观点、道德两难讨论、新方法、作品解读、新体验、虚构写作、理论、创意表达、复杂新颖想法、未来理论、抽象哲学和创意解决方案共 12 道。英文与截图位置见 questions.js。依据此前已读取的十张截图，不是新编题。

每题 weights.ei / weights.ns 的 +1 表示赞成支持 E / N，-1 支持 I / S，0 不参与该维度。每组百分比 = Σ(3×|权重| + 回答×权重) / Σ(6×|权重|) ×100；回答为 -3 至 +3。引擎支持同题双维度独立计分，但本题库没有经过验证的跨维度权重，因此每题只归入主要维度，不因同一句出现社交/讨论而重复算分。

电话、人脉压力、道德讨论、创作职业等题可能受习惯、紧张、兴趣与经验影响；按用户要求完整纳入相关题，不代表单题具有独立诊断效力。其他 36 题涉及决策中的事实与情绪、规划与截止日期、压力与自信等，未混入 N/S。

N/S 概念参考：https://www.themyersbriggs.com/en-us/support/mbti-facts
